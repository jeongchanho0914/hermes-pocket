# Hermes Pocket

모델 API에 직접 연결하는 Android 모바일 에이전트 **v0.12 베타**입니다.

**외부 연결은 설정한 모델 API, 기본 브라우저의 웹 검색과 선택적 검색 API입니다.** 대화 UI, 도구 선택·실행 루프, 사용자 승인,
기기 제어, 메모리와 대화·실행 기록 저장은 휴대폰에서 처리합니다.
PC, 별도 Python 런타임, Hermes 중계 서버는 Android 앱의 실행에 필요하지 않습니다.

**원본 Hermes Python 엔진 전체를 Android에 이식한 앱은 아닙니다.** 자체 Java 에이전트
루프로 모델의 도구 호출과 결과를 처리합니다. 실제 SKILL.md 저장·선택과 메모리·대화 검색을 지원합니다. 원본 Python 엔진·브라우저·크론·음성 전체는
현재 배포 APK에 포함되지 않습니다. Android 플랫폼 셸을 실행하는 실제 터미널은 포함됩니다. 원본 엔진 내장 검증은 `engine-spike/`에서 진행합니다. API 제공자나 외부 모델 서버가 추론을 담당하며, 모델 가중치를
APK에 포함하지 않습니다.

설치 파일: [hermes-pocket-v0.12.apk](dist/hermes-pocket-v0.12.apk) · Android 8.0 이상.
전체 앱 제어 범위와 자동 승인·승인 요청을 따로 선택할 수 있습니다. Shizuku는 휴대폰에서 실행되는 선택적 시스템 제어 도우미이며, Shell UID 2000은 Root UID 0과 다릅니다. 기본 웹 검색은 실제 기본 브라우저를 열고 Hermes 작업을 유지합니다. 브라우저는 화면에 표시되며, 검색 완료는 실제 화면으로 확인해야 합니다. 명시적 API 검색 대체 경로에서 Mwmbl·Tavily·SearXNG를 선택할 수 있습니다.
기기별 검증 범위와 제한은 [검증 보고서](docs/TEST_REPORT.md)를 확인하세요.
버전은 v0.01 → v0.02 → v0.10 → v0.99 → v1.00 순서로 올립니다.
[버전 관리](docs/VERSIONING.md), [공식 Hermes 참조](docs/HERMES_REFERENCE.md).

v0.12에서는 작은 뇌 아이콘·`thinking...`·실제 경과 시간을 표시하고, 실제 제공자가 보내는 생각 내용만 펼쳐 봅니다. 전송/중지 전환, 백그라운드 작업, 기기 도구/권한 분리, 접힌 스킬·메모리 문서 목록을 제공합니다. `USER.md`와 `MEMORY.md`, 추가 문서 및 모델별 문맥 요약을 지원합니다. [문맥 처리](docs/CONTEXT_COMPACTION.md), [자동 오류 기록](docs/ANDROID_DIAGNOSTICS.md), [v0.12 검증](docs/android-v012/TEST_REPORT.md).

## 모바일 GUI 보기

`docs/mobile-preview.html`을 브라우저에서 여세요. 휴대폰 크기로 메뉴와 입력창을
직접 조작할 수 있고, 위 선택기에서 화이트·블랙 화면을 바꿀 수 있습니다.
`docs/design-gallery.html`은 비교 갤러리이며 `docs/preview.html`은 앱 화면 자체입니다.

ChatGPT/Claude 모바일 화면을 참고해 단순한 헤더·대화 영역·둥근 입력창으로 정리했습니다.
모바일 전용 UI로, 넓은 창에서도 데스크톱 사이드바로 바뀌지 않습니다. 작은 상단 메뉴,
오른쪽 사용자 말풍선, 평면 AI 답변, 하단 입력창으로 구성했습니다. 메뉴에서 대화 검색,
새 대화, 저장 대화, 설정으로 이동합니다. 기기 도구·메모리·기록은 설정에서 엽니다.
메시지·코드 복사, 기본 Markdown과 표, 스트리밍 중 이전 메시지를 읽을 때 스크롤 유지,
최신 메시지로 이동을 지원합니다.

화면은 **화이트·블랙** 두 가지입니다. 작성 중인 메시지·API 설정·메모리는 유지됩니다.
중앙에는 공식 Hermes 저장소의 캐릭터 원본을 포함했습니다.
[이미지 출처 및 라이선스](docs/HERMES_ASSETS.md).
설정은 항목별 화면으로 구성하며, ＋ 버튼에서 로컬 스킬과 도구 플러그인을 선택합니다.

채팅에 도구별 진행·승인 대기·완료·실패 기록과 공개 작업 설명을 표시합니다. 작업 정보에는
검색어·검색 결과 수, 터미널 명령·종료 코드·안전한 출력 요약 등을 표시하며, 대화를 다시 열어도
별도 작업 기록 테이블에서 복원합니다. MiMo 공식 API가 공개하는 생각 출력은 별도 영역에 실시간 표시하며, 펼쳐 읽고 대화에서 다시 볼 수 있습니다. 다른 제공자의 비공개 추론은 표시하지 않습니다. 요청·응답 수신·생각·도구 준비·답변 작성과 경과 시간을 실제 스트림에 따라 표시합니다. 앱 재시작 후
확인되지 않은 미완료 기록은 실행 중이라고 단정하지 않습니다.

원본 Hermes 스킬 210개와 리소스를 APK에 포함했습니다. 209개는 개별 가져오기가 가능하며,
1개는 원본 파일이 파일당 1 MiB 한도를 초과해 가져오기를 제한합니다. 저장 한도는 256개이며,
스킬은 사용자가 설치·선택하고 생성·수정·ZIP 내보내기를 할 수 있습니다. 원본 문서가 포함됐다고
문서가 요구하는 모든 Python·데스크톱 도구가 구현되는 것은 아닙니다.
[원본 기능 비교표](docs/HERMES_FEATURE_MATRIX.md), [원본 스킬 라이브러리](docs/hermes-skill-library.md).

입력창의 모델 선택과 생각 수준 선택은 독립된 버튼·팝업입니다.
모델 목록은 최대 5개 행을 보여 주고 나머지는 세로 스크롤합니다. 빠른 모델 선택에는
모델 목록만 표시하며 모델 ID 직접 입력은 모델 설정 화면에서 제공합니다.
아직 모델을 설정하지 않았다면 두 선택 버튼은 비활성화되고 중앙 안내로 모델 설정을 엽니다.
상단 제목은 버튼이 아니며, 현재 대화는 별도 메뉴 대신 대화 내역에서 표시합니다.
브라우저는 실제 API 호출·기기 조작·저장을 흉내 내지 않습니다.

```bash
python3 scripts/make_preview.py
# Playwright와 Chromium이 준비된 Python 환경에서 화면 캡처 재생성
python3 scripts/capture_designs.py
# 선택: 로컬 브라우저 서버
python3 -m http.server 8780 --bind 127.0.0.1 --directory docs
```

## 일반 휴대폰 조작

v0.11에는 최근 앱·알림·빠른 설정 열기, 길게 누르기, 접근성 범위 정보에 따른 슬라이더 조절,
미디어·벨소리·알람·알림 볼륨과 화면 회전 고정이 추가됐습니다. 일반 설정 화면은 신뢰하는
시스템 앱의 실제 창·제목·리소스 식별이 확인될 때만 읽고 조작하며, 인증·권한·알 수 없는
화면은 보호합니다. 일부 Samsung 제목은 실기기 시스템 APK의 리소스로 확인했으며,
리소스 확인이 실기기 동작 검증을 의미하지는 않습니다.

웹 링크·지도·공유·SMS/메일 작성·다이얼·알람 요청은 설치된 Android 앱에 전달합니다.
전송·통화·알람 저장을 완료했다고 단정하지 않습니다. 전체 기기 범위, 잠금 해제,
활성 요청, 도구 플러그인과 승인 설정을 확인합니다. Root UID 0은 부여되지 않으며,
Shizuku의 실제 Shell UID 권한과 Android의 제한을 그대로 따릅니다.
[일반 조작 범위 감사](docs/HERMES_ANDROID_HUMAN_CONTROL_AUDIT.md), [Android 앱 연동](docs/ANDROID_PHONE_INTENTS.md).

## APK 빌드

Linux x86_64, Python 3.10+, Tkinter, JDK 17 또는 21이 필요합니다.
Android API 35와 Build Tools 35.0.0을 사용합니다.

```bash
python3 scripts/build_gui.py
```

GUI에서 SDK 약관과 다운로드 안내를 확인하고 빌드를 시작하세요. 준비된 SDK가 없으면
Google 공식 저장소에서 `.toolchain/`으로 내려받습니다. 성공한 빌드만 다음 결과를 생성합니다.

```text
dist/hermes-pocket-v0.09.apk
dist/signature-verification.txt
dist/build-info.json
```

CLI는 `scripts/bootstrap_build.py`와 `scripts/build.py`를 제공합니다.
개발 서명 키와 비밀번호는 `.signing/`에 저장됩니다. 업데이트를 위해 같은 키를 보관하고
이 폴더를 공유하지 마세요. 제조사 System 권한을 부여하는 키는 아닙니다.
Android Studio 프로젝트도 포함하지만 Gradle Wrapper는 포함하지 않습니다.

## 빌드 후 모델 API 연결

설치한 앱에서 **메뉴 → 설정 → 모델 설정**을 엽니다.

1. 제공업체를 선택합니다. 기본 API 주소는 자동으로 설정됩니다.
2. 해당 업체의 API 키를 입력해 저장합니다. 직접 설정은 API 주소도 입력합니다.
3. 실제 API에서 모델 목록을 불러와 선택하거나 모델 ID를 직접 입력합니다.
4. 생각 수준을 선택한 뒤 연결을 테스트하고 대화를 시작합니다.

제공업체를 바꾸면 이전 업체의 키를 새 업체로 보내지 않도록 인증 정보·모델·생각 수준을
초기화합니다. 기존 저장 설정은 API 주소에 맞춰 제공업체를 분류합니다.
MiMo 스트림의 JSON null은 도구 이름에 붙이지 않으며, 도구 호출 후 생각 정보를 모델 요구에 맞춰 재전송합니다.
현재 배포 엔진은 `/chat/completions`의 SSE 스트리밍과 function calling을 사용합니다.
직접 연결하는 API와 모델이 이 형식을 지원해야 합니다. Claude 등 다른 모델도
OpenRouter가 제공하는 호환 API를 통해 선택할 수 있습니다. Anthropic Messages나
OpenAI Responses 전용 모델의 직접 실행, 구독 계정 OAuth 로그인은 구현하지 않았습니다.

기본 모델과 기본 생각 수준은 기기에 저장되어 앱 재실행·새 대화에도 적용됩니다.
모델 설정 안에서 제공업체 변경, API 키 수정, 새 연결을 진행할 수 있습니다.
Hermes 원본 단계 `minimal → low → medium → high → xhigh → max → ultra`와
생각 끄기(`none`), 제공업체 기본값(`auto`)을 선택합니다. 원본과 마찬가지로 `ultra`는
API에 `max`로 전달하며, 제공업체별 지원 범위에 맞춰 실제 전달값을 표시합니다.
지원 여부는 제공업체와 모델에 따라 다르며 API가 거부할 수 있습니다.
모델 목록만 확인한 연결 테스트와 선택한 모델의 실제 응답을 확인한 테스트는 구분합니다.
도구 호출과 기기 작업의 성공은 실제 대화에서 별도로 확인합니다.
사용량에 따른 API 비용이 발생할 수 있습니다.

＋ 팝업에서 응답 스타일·실제 저장한 SKILL.md·내장 도구 플러그인을 선택합니다.
일반·글쓰기·계획·코딩은 응답 스타일이며, 실제 스킬 파일과 구분합니다.
설정 → 스킬에서 파일의 내용을 저장·수정하고 선택하면 대화마다 읽어 적용합니다.
플러그인 설정은 변경 사항 저장으로 적용하며 실제 네이티브 도구 개수와 이름을 표시합니다.
플러그인을 끄면 도구를 제공하지 않고 강제 호출도 거부합니다.

웹 검색의 기본 제공자는 키가 필요 없는 Mwmbl API입니다. Tavily는 별도 API 키를 저장해 선택할 수 있습니다.
검색과 공개 페이지 읽기는 제공자별 지원 범위에 따라 실제 결과 또는 오류를 반환합니다.
모델 키와 웹 검색 키는 분리해 암호화합니다.
외부 Python 실행 파일·임의 스킬 스크립트를 실행하는 기능은 현재 배포본에 없습니다.

HTTPS가 기본입니다. 로컬 모델 API용 HTTP는 휴대폰 내부 또는 사용자가 명시적으로 허용한
사설 LAN IP에만 허용합니다. 별도 Hermes 엔진 모드와 원격 작업 조회·취소 경로는 제거했습니다.
이전 버전의 Hermes 중계 연결 설정은 주소·모델·토큰을 초기화하고 API 전용으로 이전합니다.
기존 직접 API 설정, 대화·메모리·앱 허용 목록은 보존합니다.

## 실제 터미널과 스킬

설정 → 터미널에서 명령을 직접 실행하거나 대화에서 `terminal` / `process_manage` 도구를 사용합니다.
원본 Hermes의 도구 이름과 실행·프로세스 관리 방식을 Android에 맞춰 구현했습니다.
`android-terminal` SKILL.md를 최초 실행 시 로컬 스킬에 추가하며, 사용자가 편집한 문서는 덮어쓰지 않습니다.

기본 백엔드는 앱 UID의 `/system/bin/sh`와 비공개 작업 폴더입니다. Shizuku 백엔드는 명시적으로 선택하고,
실제 연결·전체 기기 범위·소유자 승인을 확인한 뒤 Shell UID2000 또는 실제 서비스 UID로 실행합니다.
Root를 설치하거나 없는 권한을 있다고 표시하지 않습니다.

실제 출력·종료 코드, 백그라운드 세션, 조회·대기·로그·stdin 입력·EOF·작업 중단을 지원합니다.
정상 종료한 포그라운드 명령의 `cd`와 `export`를 다음 명령에 이어갑니다. 강제 종료·`exit`·`exec`로
상태 스냅샷을 만들지 못하면 유지 여부를 실패로 반환합니다. 백그라운드 명령은 포그라운드 환경을 덮어쓰지 않습니다.
백그라운드 작업은 알림/작은 창에서 진행 상태를 확인하고 중단할 수 있으며, 앱 잠금·권한 해제·시간 제한을 따릅니다.
현재 명령 시간 제한은 1~120초이고 기본값은 30초입니다.

파이프 기반 터미널이며 PTY·완전한 Linux 배포판·Python 패키지 환경을 포함하지 않습니다.
`pty=true`는 명확한 지원 오류를 반환합니다. 임의 명령으로 새 프로세스 그룹을 별도로 만든 작업까지
종료를 보장하지는 않습니다. 원본의 Docker·SSH·원격 실행·프로세스 handoff 등은 구현하지 않았습니다.
앱의 API 키를 셸 환경에 주입하지 않으며, 감사 기록에 명령/입력/출력 원문을 남기지 않습니다.
명령 결과는 선택한 모델 API의 도구 응답에 포함될 수 있습니다.
[원본 계약과 Android 차이](docs/ANDROID_TERMINAL_REFERENCE.md).

## 휴대폰 도구

활성화한 도구를 모델이 호출하거나 **설정 → 기기 도구**에서 직접 실행합니다. 실제 제공 목록은 저장한 플러그인 설정에 따라 표시됩니다.

| 기능 | 조건 |
|---|---|
| 기기 상태·앱 목록 | 기본 Android API |
| 앱 실행·설정 화면 열기·미디어 볼륨 | 전체 앱 제어 범위 및 선택한 승인 방식 |
| 화면 밝기 | WRITE_SETTINGS 수동 허용 또는 실제 지원하는 Shizuku 연결 + 선택한 승인 방식 |
| 화면 이미지·요소 읽기, 클릭·입력·스크롤·좌표 제스처 | 접근성 수동 활성화 + 전체 앱 제어 + 선택한 승인 방식 |
| 프로세스 조회·일부 시스템 설정·일반 앱 종료 | 실제 Shizuku Shell 또는 이미 설치된 Root 연결 + 선택한 승인 방식 |

Root를 새로 획득하거나 제조사 서명·시스템 이미지를 설치하지 않습니다.
화면 조작은 접근성 노드와 좌표 제스처를 사용합니다. 화면 정보는 앱·창·영역에 연결되고 45초 후 만료됩니다.
조작 뒤에는 새 화면 정보를 확인하며, 전달 성공만으로 사용자 목표 달성을 주장하지 않습니다.
`capture_screen`은 실제 화면 이미지를 현재 모델 API로 보냅니다. Android 11 이상과 화면 캡처 접근성 권한,
이미지를 이해하는 모델이 필요합니다. Android 14 이상에서는 대상 앱 창만 캡처합니다.
편집 필드 픽셀을 가리고 비밀번호·인증 화면, 잠금 화면 및 가려진 화면은 거부합니다.
이미지는 대화 DB·감사 기록에 저장하지 않고 해당 모델 요청에만 포함합니다.

다른 앱에서 작업할 때 작은 창에 진행 상태·입력창·중단 버튼이 표시됩니다. 드래그로 이동하고 접을 수 있으며,
작업 후 같은 대화에 이어서 요청할 수 있습니다. 자동으로 키보드를 열지 않습니다.
설정에서 작은 창을 끌 수 있습니다. 화면을 잠그거나 접근성을 해제하면 숨깁니다.
작업 대상과 겹치는 자체 창은 조작 동안 치웁니다. 다른 앱의 오버레이를 임의로 무시하지 않습니다.
승인 요청 방식에서는 앱의 승인 창 또는 알림에서 직접 허용합니다. 알림 승인을 사용하려면 알림 권한이 필요합니다.
음성 및 채팅 입력창의 파일 첨부는 구현되어 있지 않습니다.

한 번에 한 작업을 실행하고 중단 버튼을 제공합니다. 모델 요청은 기본 최대 24회이며,
설정 → 에이전트 실행 설정에서 2~64회로 조정합니다. 전송할 대화 문맥의 글자 한도도
조정할 수 있습니다. 오래된 대화는 도구 호출·결과가 완성된 턴 단위로 요청에서 제외하고,
전체 기록은 기기에 보존합니다. 이는 원본 Hermes의 의미 기반 요약과 다릅니다.
끊긴 스트림의 부분 도구 요청은 실행하지 않고, 거부한 도구는 같은 실행에서 자동 재시도하지 않습니다.
`verified: false`는 실행 전달만 확인한 상태이며 실제 결과를 보장하지 않습니다.
대화·실행 기록은 SQLite에, API 키는 Android Keystore 기반 AES-GCM으로 저장합니다.
메모리는 최대 4,000자이며 직접 편집하거나 모델이 승인받아 변경할 수 있습니다.
과거 대화는 session_search로 검색하고, 실제 SKILL.md를 도구로 읽거나 관리합니다.
작업 중 화면과 대화는 연결한 모델 API로 전송될 수 있습니다.

## 검증

```bash
python3 tests/run_jvm_tests.py
python3 -m unittest discover -s tests -p 'test_versioning.py' -v
# 기존 별도 어댑터만 검증
python3 -m unittest discover -s tests -p 'test_transport.py' -v
# Playwright + Chromium 환경에서 GUI 검증
python3 -m unittest discover -s tests -p 'test_ui.py' -v
python3 -m unittest discover -s tests -p 'test_designs.py' -v
```

브라우저 검사는 UI와 브리지 계약을, JVM 검사는 실제 Java API 루프를 검증합니다.
Android 에뮬레이터와 갤럭시의 실제 권한·화면·조작 검사 결과는 [검증 보고서](docs/TEST_REPORT.md)에 별도로 기록합니다.
빌드 성공이나 테스트용 브리지 응답은 모든 앱에서 동작한다는 증거가 아닙니다.
`test_transport.py`는 남겨둔 이전 Python 어댑터의 전송 테스트이며 Android의 직접 API
추론 검증을 대신하지 않습니다.

```text
app/       Android Java 기능과 로컬 HTML/CSS/JS GUI
scripts/   SDK 준비·APK 빌드·미리보기 생성 도구
tests/     실제 Java 런타임 TCP API 검사·GUI·버전 관리·기존 어댑터 검사
docs/      모바일 미리보기·스타일 비교·검증 보고서
server/    이전 별도 Hermes 어댑터 소스: 현재 Android 앱에서 연결하지 않음
```
