# Hermes 기능 대조표

확인일: 2026-10-04. 기준은 공식 Hermes 문서와 upstream 소스, 그리고 이 저장소의
실제 Android Java 코드입니다. 이 문서에서 **구현**은 코드가 존재한다는 뜻이며,
완성된 APK·휴대폰·실제 제공자 검증 결과는 `TEST_REPORT.md`에서 별도로 확인해야 합니다.
v0.03 배포본과 작업 중인 다음 버전의 기능을 구분합니다.

## 원본과 실행 방식

공식 [Hermes 저장소](https://github.com/NousResearch/hermes-agent)는 Python 기반
에이전트와 다양한 실행 환경을 제공합니다. 공식 Android/Termux 패키지도 있으므로
원본이 Android에서 실행되지 않는다는 설명은 정확하지 않습니다. 이 APK는 원본
Python 런타임을 묶지 않고 Java로 대화·도구 실행을 휴대폰 내부에 구현한 비공식 앱입니다.
확인 시점의 [공식 Termux 안내](https://hermes-agent.nousresearch.com/docs/getting-started/termux)는
패키지가 현재 동작하지 않으며 수정 중이라고 명시합니다. 설치 안내의 존재와 정상 실행
검증을 구분해야 합니다. 원본 엔진 도입 경로는 [별도 검토](UPSTREAM_ANDROID_ENGINE_FEASIBILITY.md)를 참고하세요.

웹 검색을 추가하면 외부 연결에는 **선택한 모델 API와 사용자가 설정한 웹 검색 API**가
포함됩니다. 별도 PC나 Hermes 중계 서버는 필요하지 않습니다. 앱 화면에 검색 토글만
만드는 것은 웹 검색 구현으로 계산하지 않습니다.

## 실제 로컬 도구의 계약

`LocalAgentTools.java`의 도구는 기존 에이전트가 함수 호출로 실행하도록 설계했습니다.
등록과 실행은 같은 도구 목록을 사용해야 하며, 모듈을 끄면 강제 호출도 거부해야 합니다.

- `memory`: 기존 메모리를 읽고, 항목 추가·정확한 문자열 교체·삭제를 수행합니다.
  교체·삭제 대상은 정확히 한 번 일치해야 하며 승인 중 원본이 바뀌면 저장하지 않습니다.
- `session_search`: 소유자의 저장 대화만 문자 검색합니다. 최대 10개, 발췌당 800자이며
  인증 설정·API 키·개인 파일은 검색하지 않습니다. SQL 매개변수와 LIKE 이스케이프를 사용합니다.
- `skills_list` / `skill_view`: 저장한 스킬의 목록·설명을 먼저 보고 필요할 때 문서를 읽습니다.
- `skill_manage`: 이름·설명·Markdown 본문으로 실제 `SKILL.md`를 저장하거나 삭제합니다.
  모델의 변경은 승인을 요구합니다. UI의 명시적인 저장/삭제 버튼은 직접 사용자 작업입니다.

`LocalSkillStore.java`는 스킬 이름의 경로 이동·심볼릭 링크를 거부하고, 개인 저장소에
최대 64개·본문 16,000자·설명 200자의 문서를 원자적으로 저장합니다. SKILL.md 머리말은
앱이 이름·설명에서 생성합니다. 스킬 내용은 도구 권한이나 사용자 승인으로 취급하지 않습니다.

## 우선 확인해야 하는 검증

1. 실제 도구 켜기 → 저장 → 강제 종료 → 재실행 후 같은 활성 목록과 API 도구 스키마 유지.
2. MiMo 생각 모드에서 실제 함수 호출 → 결과 전달 → 후속 응답 성공. 숨은 추론은 UI에 노출하지 않음.
3. 실기기에서 상태·앱 목록을 읽고, 승인한 볼륨·앱 실행 결과를 관찰. 접근성·Root는 권한 부족을 정확히 반환.
4. 실제 웹 검색 API가 반환한 URL·내용으로 답변하고, 키 없음·권한/요금·검색 실패를 구분.
5. 메모리 승인 거절·승인 저장·재실행 유지·이전 대화 검색·스킬 생성/선택/적용/삭제 확인.
