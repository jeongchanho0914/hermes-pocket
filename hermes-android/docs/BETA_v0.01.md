# Hermes Pocket v0.01 beta

Android 8.0 이상에서 사용할 수 있는 비공식 Hermes 참고 모바일 에이전트입니다.

## 시작

1. `dist/hermes-pocket-v0.01.apk`를 휴대폰으로 옮겨 설치합니다.
2. 메뉴 → 설정에서 OpenAI 호환 모델 API 주소·API 키·모델 ID를 입력합니다.
3. 저장 → 연결 테스트 후 채팅 화면에서 메시지를 보냅니다.
4. 화면 제어가 필요하면 기기 도구에서 허용한 앱과 접근성을 직접 설정합니다.

연결 테스트는 작은 모델 요청을 실제 전송하므로 API 사용량에 포함될 수 있습니다.
Claude를 포함한 모델은 OpenAI 호환 API를 제공하는 제공자 경로에서 사용합니다.
이 베타에는 Anthropic Messages API 전용 어댑터나 구독 계정 로그인 기능이 없습니다.

## 포함 기능

- 10가지 모바일 스타일, 스트리밍 대화, Markdown·표·코드 및 메시지 복사
- 대화 검색·복원·삭제, 로컬 메모리 편집, 기기 작업 감사 기록
- 휴대폰 내부에서 실행되는 도구 호출 루프와 13개 Android 도구
- 작업별 승인, 거부 후 자동 재시도 차단, 실행 중단
- 끊긴 스트림의 부분 도구 요청 차단, 미완료 응답 보존
- 모델 요청 횟수 및 전송 문맥 크기 설정
- Android Keystore로 암호화한 API 키, SQLite 대화·도구 결과 저장

## API만 외부에 연결

| 처리 | 위치 |
|---|---|
| 화면·채팅 입력 및 응답 표시 | Android 로컬 WebView 번들 |
| 모델 요청 구성·도구 호출 해석·반복 실행 | 휴대폰의 Java DirectAgent |
| 승인·기기 조작 | Android native API·접근성·기존 Root |
| 대화·메모리·기록·키 저장 | 휴대폰 SQLite·설정·Keystore |
| 모델 추론 | 사용자가 설정한 모델 API |

앱이 외부 웹 페이지·CDN·폰트·통계 SDK를 불러오지 않습니다. WebView의 외부 리소스와
탐색은 차단합니다. 모델 API 요청은 `Net.java`에서 처리하며 리다이렉트는 따르지 않습니다.
별도 PC·Python·Hermes 중계 서버가 필요하지 않습니다. API로 보낼 대화와 도구 결과에는
요청한 작업에서 읽은 화면 정보가 포함될 수 있습니다.

## 베타 범위

원본 Hermes Python 엔진 전체를 담은 앱은 아닙니다. 원본 Skills·플러그인·터미널·크론·
브라우저 자동화·음성·첨부·자동 학습 메모리·의미 기반 요약은 포함하지 않았습니다.
구현과 공식 참고 자료는 `docs/HERMES_REFERENCE.md`, 실제 검증 범위는
`docs/TEST_REPORT.md`, 업데이트 번호와 서명 키 보관 규칙은 `docs/VERSIONING.md`를 확인하세요.
